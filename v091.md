## 1. `trader` module (live order orchestration)

A new top-level module that takes a **`Broker`** instance (from `broker`) and a
**`BaseStrategy`**, and runs the strategy against live/real-time data, placing
real orders through the broker.

- `Trader(broker, strategy, config)` — mirrors `Simulate(config).run(...)` but
  live. Reuses the same `Signal` / `ExitSignal` / position-sizing / SL-TP logic
  as `simulate/_engine.py` so backtest and live behave identically.
- Position sizing, SL/TP, risk-free, trailing — reuse `simulate` internals
  (factor the sizing/SL math out of `_engine.py` into a shared helper so both
  the backtest engine and the live trader call the same code — single source of
  truth).
- State reconciliation: on start, read `broker.open_positions()` /
  `broker.open_orders()` so a restart on the VPS does not double-open.
- Safety: `dry_run` flag (log intended orders, don't send); hard kill-switch;
  max-daily-loss guard; graceful shutdown that cancels working orders.
- Persistence: write open-trade state to disk so an SSH session drop / restart
  resumes cleanly.

## 2. Real-time simulation (`simulate` live mode)

Feed **socket candles** (from `broker.stream_candles(...)` / `data.Collector.stream`)
into the simulation engine incrementally.

- Refactor `_simulate_loop` so it can be driven candle-by-candle (a generator /
  step function) instead of only a full-batch loop.
- `Simulate(config).run_live(strategy, broker)` — seed with historical candles,
  then advance one candle per closed socket bar, emitting updated
  `SimulateReport` snapshots.

## 3. Live-updating chart + report

Both the `visual.Chart` and `report` servers already run on WebSocket daemon
threads — push incremental updates instead of a one-shot render.

- `chart.stream_from_atk(candle)` already exists — extend to also push new
  position boxes / SL-TP line updates as trades open/close live.
- `report` server: add a `push_update(report)` that re-broadcasts fresh stats to
  the open report page over its existing WebSocket.
- The pattern: **run a sim on old candles, display it the existing way, then keep
  updating both chart and report from the real-time feed.**

## 4. Reusable "live runner" helper

A single library entry point so any strategy + simulation can go live in a few
lines (used by the ichimoku demo below, and by anything else):

```python
run_live(
    strategy=IchimokuStrategy(cfg),
    broker=Broker("metatrader", server=..., login=..., password=...),
    sim_config=SimulateConfig(...),
    history="last_1000" | {"start": "2025/01/01"},
    show_chart=True, report_mode="webpage",
)
```

Seeds history → simulates → shows chart+report → subscribes to the socket →
advances the sim and refreshes the display on every closed candle.

## 5. Ichimoku strategy demo — mode 2

Extend `ichimoku_strategy.py` with a second run mode (mode 1 = load CSV & show,
already done):

- Connect to MetaTrader via `Broker("metatrader", ...)`.
- Grab the **last 1000 candles** OR **from a date until now**
  (`broker.fetch_last_candles(...)` / `data.Collector`).
- Simulate them and show the result **and keep updating the output live** from
  the socket feed — all via the reusable `run_live(...)` helper (item 4), so any
  strategy gets this for free.
